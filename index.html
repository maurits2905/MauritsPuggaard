Anonymous counters

The “Stats” panel displays a view count and a like count. These are powered by CountAPI, a free anonymous counter service. A single HTTP request is made per browser session — no IP address, no fingerprint, no personal identifier is stored on my end.

If you click “Love this portfolio”, a flag is stored in your browser’s localStorage so the counter increments only once. That flag never leaves your device.
